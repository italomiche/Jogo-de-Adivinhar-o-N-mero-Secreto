Projeto: Controle de Ingressos para Evento Escolar
1. Introdução

Este projeto tem como objetivo controlar a quantidade de pessoas em um evento escolar, respeitando o limite de 100 ingressos e no máximo 20 convidados.

2. Desenvolvimento

Nesta etapa, serão solicitadas as quantidades de alunos, monitores e convidados. Depois, será calculado o total de pessoas.

3. Análise dos Resultados

O programa verificará se o total de pessoas está dentro do limite de 100 ingressos e se a quantidade de convidados não ultrapassa 20.

4. Conclusão

Com este projeto, aprendemos a utilizar condições na programação Python para resolver um problema do cotidiano.
